Type C vs Type X drywall: what actually differs and what it does to your count

By The ReadMyBlueprint Team · Nov 25, 2026

Type X is the baseline fire-rated gypsum board and is defined in ASTM C1396. Type C is a manufacturer's own enhanced Type X, with extra core additives, and it is not defined in any ASTM standard. On a takeoff the difference is simple: count them as separate board lines, and do not swap one for the other unless the listed assembly allows it.

Type XType C
Defined byASTM C1396, for 1/2 in., 5/8 in. and 1 in. boardNo ASTM definition; a manufacturer designation used in UL listings
CoreGypsum with glass fiberType X plus more glass fiber and shrinkage-control additives
Thicknesses1/2 in., 5/8 in., 1 in.1/2 in. and 5/8 in.
Swap ruleCannot replace a listed Type COften accepted as an upgrade where Type X is listed; verify the listing

Sources: National Gypsum and Georgia-Pacific, read Nov 25, 2026. Both are manufacturers, so check the current UL listing or GA-600 for the assembly you are pricing.

Why do the plans say Type C at all?

Some tested assemblies are listed with a Type C face layer because the manufacturer designed that board to resist shrinkage as the core heats in a fire. The architect lists it in the wall-type legend or in a keynote. If you only see "5/8 in. GWB, rated" and no type, you do not have enough to order.

What breaks on the count when both types are in one set?

The usual miss is lumping all rated board into one "5/8 Type X" total. A 1-hour corridor wall and a 2-hour shaft wall on the same floor can use different boards, so the SF has to follow the wall type, not the thickness. When a legend line gives a thickness and a rating but no board type, ReadMyBlueprint flags it for your confirmation instead of picking Type X for you.

Worked example (assumed numbers): 200 LF of 2-hour wall, 14 ft high, Type C on both faces in two layers: 200 × 14 × 4 = 11,200 SF of Type C before waste. If that quantity is carried as Type X, the line is mispriced and the wrong board gets quoted by the supplier.

How do you check the board type on a plan set?

  1. Read the wall-type legend for the layer schedule. See how to read a wall type legend.
  2. Look for a UL or GA design number, because it names the board.
  3. Check the specification section for gypsum board, which often lists Type C by product.
  4. If the three disagree, send an RFI before you buy.

Frequently asked questions

Is Type C drywall better than Type X?

Type C is a manufacturer's enhanced version of Type X, made for assemblies that need more fire resistance or less shrinkage in a fire. It is not better for every wall. The tested assembly in the plans decides which board you may use.

Can I substitute Type X for Type C?

Not where the listed assembly calls for Type C. Swapping in the other direction, a listed Type C board for Type X, is generally allowed, but confirm against the listing and with the architect.

Is Type C defined by ASTM?

No. ASTM C1396 defines Type X gypsum board. Type C is a term used in UL listings to identify a specific manufacturer's product.

Do I count Type C and Type X on separate lines?

Yes. They are different SKUs with different prices and different suppliers' availability, so each gets its own square footage by wall type.
