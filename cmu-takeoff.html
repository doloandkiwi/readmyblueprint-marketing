● CMU takeoff

A block count from real wall area, not a per-square-foot rule.

CMU counts scale fast — a single-story commercial shell can run tens of thousands of blocks, and a small error rate compounds quickly. ReadMyBlueprint measures each wall's real area directly from your plan set and converts it to a block count for that wall's actual thickness.

How it works

From wall area to a block count, in three steps.

1

Measure the real wall area

Every CMU wall is measured directly from the vector geometry in your plan set — length and height, calibrated to the sheet's own printed scale.

2

Match block size from the legend

Each wall's measured thickness is cross-referenced against your wall-type legend to identify the actual block size specified (commonly 8" or 12" nominal), rather than assuming one size for the whole plan set.

3

Convert to a labeled block count

Wall area converts into a block count based on that block's real face dimensions, grouped by wall type and labeled matched, ambiguous, or needs confirmation.

Being upfront

What this doesn't do — on purpose.

Part of never presenting a guess as a measurement is telling you plainly where the line sits.

Not covered yet

  • Mortar and grout. ReadMyBlueprint counts block units — mortar joints, grout fill, and mortar mix quantities aren't calculated.
  • Reinforcement. Vertical and horizontal rebar, and bond beams, are only counted when explicitly labeled — not inferred from wall height or code requirements.
  • Lintels and special units. Bond beam block, lintel block, and other special shapes are only broken out when your plan set labels them distinctly from standard block.
  • Scanned or flat-image PDFs. The measurement is only as real as the vector geometry it comes from — a scanned page has none to measure, so those pages are called out rather than guessed at.
